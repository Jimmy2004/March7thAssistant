全部合并结果先暂存，再检查和替换。替换失败回滚已改文件和同步状态；事务日志记录到 settings/updates/。下次启动先恢复中断的事务；若中断后有人又改了相关文件，停止启动并保留文件，显示备份位置。更新与游戏任务共用互斥锁，禁止边运行边替换。成功后程序退出，重新启动才加载新代码。
