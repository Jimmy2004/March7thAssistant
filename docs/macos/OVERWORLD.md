# 云游戏锄大地

## 本机使用

退出旧版终端程序，重新运行 `march7th`。

1. 进入 **3 运行设置 → 3 锄大地**。
2. 选择路线版本、优先星球，以及是否切换队伍。默认路线要求 1 号位普攻远程；黄泉路线要求 1 号位黄泉。地图须已解锁，机关须符合上游路线的初始状态。
3. 首次建议选择高级设置：起始地图 `1-1_0`、单地图模式开启，再回到主菜单执行一次 `fight`。该地图适用于默认路线；其他版本应使用其实际存在的地图编号。
4. 单图确认正常后关闭单地图模式，运行整轮。开启「启用锄大地」才会把锄大地纳入「完整运行」；单独选择 `fight` 始终可以执行。

每一级输入 `0` 或 `b` 返回。特殊物品领取总开关与三项子开关均需按需求开启；默认关闭。该功能会执行对应路线中的游戏内购买或领取动作。

```sh
march7th --task fight
march7th --task fight --debug
march7th --task fight --schedule 08:00
```

定时运行要求终端进程保持运行，Mac 不处于睡眠状态。等待期间关闭游戏。每轮成功、失败重试耗尽或 Ctrl+C 后，终端运行器关闭项目专用浏览器。

## 实现

`Fight.start()` 的云游戏分支调用 `module/fight_cloud/runner.py`，Windows 本地分支维持原逻辑。原版 Fhoe-Rail 的地图导航、模板匹配、按时移动、疾跑检测、视角校准、秘技和自动战斗逻辑在隔离的 Python 子进程中执行。

子进程通过私有继承的 socket 向主进程请求截图和输入，主进程使用已有云浏览器。有效画面固定 1920×1080，截图在子进程转成 BGR；不抓 Mac 桌面，不操作系统光标。移动和截图请求用锁串行，兼容上游疾跑检测线程。

视角移动使用浏览器中的虚拟 Pointer Lock 状态，并给可信 CDP 鼠标事件提供相对位移。原引擎用小地图箭头测量和校准旋转比例；测不到有效旋转时失败退出，不能继续盲走。任务结束释放所有按键和鼠标，并移除注入脚本。

移植还兼容了上游旧的 `Handle.mouse_move` 调用，并把原引擎战斗超时返回成功的情况改为失败。地图传送、交互和机关错误均不记录完成时间。特殊领取关闭、非领取日、地图黑白名单等明确允许的跳过行为单独计数。记录完成时间仅发生在整个子进程报告完成且正常退出之后。

单图默认时限 900 秒（配置 `fight_map_timeout`，30–3600 秒），整轮 `fight_timeout` 默认 12 小时，最多 24 小时。单图计时也覆盖进入路线前的视角校准；整轮主进程监控同时覆盖没有截图/输入请求的卡死。

## 资源与更新

Fhoe-Rail 来源：`linruowuyin/Fhoe-Rail`，固定修订 `86cea0f01dc70c3ff597a2ad45907cb44624586f`。压缩包 SHA-256：`8b9cb906ab6448acda12a8f01e36c3755c47fd14d3dd40adf3243d48ed19f6c9`。

清单位于 `module/fight_cloud/engine.json`。首次运行或设置子菜单 11 按需下载、验证并安装，仅保留 map JSON、picture 图片、所需识图/流程代码、版本号和 GPL-3.0 许可证。不会安装上游 Windows 依赖、可执行文件、桌面驱动、Tk 或全局键盘监听。配置中的 orjson 字节读写由隔离子进程内的标准库兼容层处理，无新增依赖。

资源安装在 `3rdparty/Fhoe-Rail-cloud/<revision>/`，采用临时目录和原子重命名；下载中断不会覆盖已安装资源。每次执行校验文件摘要。配置及视角校准保存在 `settings/fhoe-cloud.json`，独立于资源目录。

当前包含 default、default_lite、HuangQuan、technique、reward 五个版本；technique 是上游已停止维护的历史路线。March7th 官方源码更新不会覆盖本适配器或 `tasks/daily/fight.py`。外部 Fhoe 引擎采用固定版本，需在兼容性验证后更新清单并随 Mac 分支发布；不会未经验证直接切换至外部引擎最新源码。
