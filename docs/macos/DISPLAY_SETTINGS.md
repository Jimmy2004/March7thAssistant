# 固定视口和云游戏画质

游戏有效视口固定为 1920×1080，devicePixelRatio 和页面缩放固定为 1。启动、重连、进入游戏及截图前重新应用设备指标；宿主屏幕、Retina 缩放与调试窗口大小不改变自动化坐标系。

菜单：3 运行设置 → 2 云游戏画质。

| 终端选项 | 保存值 | 网页 graphicsMode |
| --- | --- | --- |
| 高画质 | high | 0 |
| 省流画质 | traffic_saving | 1 |
| 极致省流 | extreme_saving | 2 |

保存于 config.yaml 的 cloud_game_video_quality。旧安装保存的数字配置会按原选择迁移为相应三档；新设置使用明确名称，避免与网页内部数值混淆。

启动时将整数 graphicsMode 合并写入 clgm_web_app_settings_hkrpg_cn；在网页初始化前注入，刷新和导航也会重新应用。保留语言、兼容模式及其它网页偏好。网页通过 applyGraphicsParams / setGraphicsMode 将该值传给云游戏播放器。设置保存失败时中止，不假装已生效。

2026-10-17 在用户已登录、已有云会话的浏览器中，分别点击三个实际选项，观察选中样式及省流提示，并读取对应 graphicsMode 为0、1、2。调试结束恢复为原来的高画质，没有刷新、关闭页面或新开云会话。

实际启动注入脚本另外验证了三档取值、重复运行不重复变更及偏好保留。1920×1080 视口测试继续保留；画质改变图像细节和流量，自动化显示区域仍固定不变。
