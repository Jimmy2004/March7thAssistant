# 固定视口和云游戏画质

2026-10-17。

游戏的浏览器有效视口固定为 1920×1080，devicePixelRatio 和页面缩放都固定为 1。启动、重连、进入游戏及截图前均重新应用设备指标；屏幕尺寸、Retina 缩放、浏览器缩放配置及调试窗口大小不能覆盖自动化坐标系。用户自定义的窗口尺寸和设备缩放启动参数被忽略，其余参数继续保留。

菜单路径：3 运行设置 → 2 云游戏画质。可选超高清、高清、标清、低清；0 或 b 返回，不保存。默认超高清，单账户的选择保存在 config.yaml 的 cloud_game_video_quality 字段。

每次启动将所选 speedLimitGearId 合并写入国服网页客户端配置，保留其它偏好；初始加载前注入，刷新或导航也会重新应用。重连浏览器时如档位变化则刷新一次，使网页重新加载配置。设置写入失败或值非法时中止启动，避免无声使用错误档位。

当前官网四档 ID 为 0、1、2、3。核对依据为官网公开网页脚本中的 loadConfig/saveConfig 消费逻辑，以及带官网公开请求头访问的 getSpeedLimitConfig 响应。源码检查与测试没有使用登录 Cookie、进入游戏或消耗云游戏时长。

验证：真实 Chrome headless、宿主缩放参数 1 和 2、800×600 初始窗口及 640×480 调整窗口下，CSS 视口和截图仍是 1920×1080、DPR=1。官网页面设为标清、刷新后仍为标清，volume 等原有配置保留。尚未登录真实账号验证播放器最终码率。

画质档位控制传输码率；固定视口提供稳定的游戏显示区域和截图/输入坐标系，不将低码率画面伪称为额外图像细节。
