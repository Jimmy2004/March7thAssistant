# Mac 云游戏终端版需求

2026-10-17 用户确认。

- 后续开发只在 Jimmy2004/March7thAssistant 中进行。
- 国服官服；优先所有 Apple Silicon Mac。Intel 后续低优先级，不宣称未经测试的系统版本已支持。
- 日常任务不显示助手 GUI 或浏览器窗口，只显示终端问答、菜单和滚动日志。需要登录时临时显示浏览器，调试模式可保持窗口。
- 需要登录时临时弹出专用浏览器并显示官网二维码，等待手机确认和网站登录成功后自动关闭窗口，复用独立资料目录回到无窗口模式，验证登录状态后继续。已登录不弹窗；调试运行保持窗口可见。
- Windows 本地游戏专属功能允许删除；云游戏可用业务功能仍是完整迁移目标，包括模拟宇宙和锄大地，不允许用空实现或仅删除平台保护冒充实现。
- 单账户。单次运行或每天指定时间重复运行。每轮成功、重试耗尽、手动停止均需关闭云游戏，等待计划时不维持游戏会话。
- 首次启动终端多轮问答；后续启动输入数字选择操作。每层问题/菜单都有返回操作。取消问答不得写入半份配置。
- Git clone + 按 README 安装依赖并运行，不交付点击即用的安装包。
- 简单编码优先 OpenCode CLI 的免费 Big Pickle 或用户 MiniMax M3，主代理负责审查与测试，避免不必要的 subagent token 消耗。

## 当前验收分层

1. 代码测试：菜单返回、参数验证、扫码等待手机确认、登录成功后转回后台、失败退出码、进程关闭、重试和调度。
2. 浏览器测试：Apple Silicon 原生 Chrome 能完全 headless 启动，已登录的正常模式不会出现窗口，不影响用户鼠标；临时登录完成后窗口关闭。
3. 云游戏实测：扫码登录、画面获取、输入、每个任务成功结果、失效重试、成功/失败后会话释放。
4. 全功能完成：外部模拟宇宙/锄大地、抽卡导出、自动剧情、流程管理、任务参数配置、消息推送均经过云端验收。

前一层通过不能代替后一层通过。

2026-10-17 补充：不论宿主环境，云游戏有效视口固定 1920×1080、DPR=1、页面缩放=1；运行设置提供官网高画质、省流画质、极致省流三档选择，每次启动加载，不能只保留注释配置。

2026-10-17 补充：正常启动先检查官方上游源码更新，菜单也提供检查入口；发现更新后询问Y/N，用户选Y才下载并选择性三方合并。保留Mac适配与用户数据，排除Windows/GUI等无关资源；冲突停止，失败回滚，成功后重启。
